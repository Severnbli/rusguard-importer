# RusGuard Importer

Приложение для создания и редактирования профилей RusGuard, управления ключами и подготовки Access-карточек.

## Запуск

**Linux:** нужен Docker Compose и графическая сессия X11/XWayland. Из папки проекта запустите:

```bash
./importer.sh
```

Скрипт скачает опубликованный образ и откроет окно приложения. Для локальной сборки вместо этого запустите `./importer.sh --build`.

**Windows:** скачайте `RusGuardImporter.exe` из артефактов workflow **Build Windows exe** в разделе GitHub Actions и запустите его. Для режима Access-базы также нужен установленный Microsoft Access Database Engine.

## Первый запуск

Задайте пароль приложения. При следующих запусках он потребуется для входа. Если пароль забыт, выберите «Забыл пароль»: приложение удалит сохранённые настройки, включая подключение и пароль БД; восстановить их нельзя.

На вкладке «Настройки» укажите подключение к PostgreSQL и нажмите «Проверить подключение». Пароль БД хранится в файле настроек зашифрованным. Должности и группы загружаются с сервера.

## Работа

Выберите режим:

- **Создание профиля:** добавьте строку и заполните ФИО, ключи, должность и группу. Фото можно выбрать и обрезать в приложении.
- **Редактирование профиля:** найдите сотрудника по ФИО, ключу или группе. Измените ФИО, полный список ключей, должность, группу или фото. «Откатить к данным из БД» отменяет изменения выбранной строки.
- **Access-база:** найдите сотрудников для карточек. Данные доступны только для просмотра; кнопка запуска создаст `.accdb` из выбранных профилей. Режим доступен только в Windows.

Excel необязателен: «Из Excel…» загружает строки в таблицу, «Шаблон Excel…» сохраняет файл-заготовку. Фото к загруженным строкам выбираются в приложении.

Формат ключей: десятичный, HEX или HEX с обратным порядком байт. Несколько ключей разделяйте запятыми, точкой с запятой, `/` или переносом строки. Фото можно сохранить из выбранного профиля в JPEG, PNG или BMP.

## Важно

- По умолчанию включён **Dry-run**: изменения проверяются, но не сохраняются. Отключите его для настоящего импорта.
- Если выключен режим частичного сохранения, любая ошибка отменяет весь импорт.
- В Linux настройки и рабочие файлы находятся в папке `data/` проекта. В Windows настройки расположены в `%APPDATA%\rusguard-importer\settings.json`.
- Access Database Engine должен совпадать по разрядности с приложением.
